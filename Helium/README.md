# Helium
- `master_preferences` applies on FIRST run only (homepage, home button,
  bookmark bar). Installer drops it into `%LOCALAPPDATA%\Helium\User Data\`
  if Helium hasn't run yet - otherwise it is ignored, change settings in UI.
- Theme: Chrome Web Store > any red/black theme (Helium takes Chrome themes).
- Recommended: Settings > Appearance > font JetBrainsMono Nerd Font where
  offered; Privacy: block third-party cookies; set Helium as default
  (installer tries `--make-default-browser`, confirm in Windows Settings).
- Suggested workspace: Komorebi ws2 (`Win+2`), like sway `$ws2`.
