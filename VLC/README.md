# VLC
Fresh installs only, lands in `%APPDATA%\vlc\vlcrc`.
- Dark Qt interface on, background cone off, snapshots to Public Pictures.
- Font for subtitles: Tools > Preferences > Subtitles/OSD > JetBrainsMono
  Nerd Font (show settings: All, for the full list).
- ws8 too (`Win+8`), next to OBS.
- If high-bitrate files stutter: Tools > Preferences > Input/Codecs >
  Hardware-accelerated decoding = Direct3D11, and bump file caching
  under Input/Codecs to ~1000ms for network shares.
