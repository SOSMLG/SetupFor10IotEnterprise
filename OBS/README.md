# OBS
- Profile: installer drops `profiles/Recording/basic.ini` into
  `%APPDATA%\obs-studio\basic\profiles\Recording\` (1080p60, MKV, high
  quality x264 - MKV survives crashes, remux to MP4 via File menu).
  If you have NVIDIA: Settings > Output > Encoder > NVENC H.264.
- Theme: stock dark (Settings > General > Theme > Dark) - matches the
  red & black setup without extra files.
- First scene (2 clicks): Sources + > Display Capture, Sources + > Audio
  Input Capture (your mic). Keep OBS on Komorebi ws8 (`Win+8`).
