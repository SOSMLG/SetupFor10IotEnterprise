# Vesktop
Deployed by installer to `%APPDATA%\Vesktop\settings.json` (only if Vesktop
has never run - never overwrite a live config).
- Theme: red & black via `quickcss.css` (Vencord > QuickCSS > Enable).
  Installer drops it into `%APPDATA%\Vesktop\settings\quickcss.css`.
- Suggested workspace: keep Vesktop on Komorebi ws5 (`Win+5`), like sway `$ws5`.
- Screen share on Wayland tricks don't apply - Windows capture just works.
  For audio share use Discord's own screen-share dialog.
